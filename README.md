# COMP.CS.320 — Data-Intensive Programming

> **Tampere University · Fall 2026**

##  About

This repository contains my coursework and exercise solutions for **COMP.CS.320 Data-Intensive Programming**. The course focuses on processing and analysing large-scale datasets using modern distributed computing frameworks.

## Topics Covered

| Week | Topic |
|------|-------|
| 1 | Introduction to the course and to big data processing platforms |
| 2 | Introduction to Apache Spark and its basic operations (DataFrame) |
| 3 | Continuing with operations and unstructured data (RDD, Dataset) |
| 4 | Streaming in Spark and introduction to storage file formats|
| 5 | Continuing with storage file formats |
| 6 | Data pipelines and data lakes |
| 7 | Cloud data warehouses |



##  Tools & Technologies

- **Apache Spark** — Distributed data processing engine
- **Databricks** — Cloud-based unified analytics platform
- **Python / PySpark** — Primary programming language & Spark API
- **Spark SQL** — SQL interface for structured data

- **Git, GitLab & GitHub** — Version control and collaboration
